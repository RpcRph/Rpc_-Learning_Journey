## 第二部分编译

在 Git Bash 中进入本目录后运行：

```bash
latexmk -xelatex "机器学习入门知识总结_Rpc.tex"
```

`latexmk` 会根据需要自动执行多轮编译，以正确生成目录、页码和交叉引用。编译结束后可运行：

```bash
latexmk -c "机器学习入门知识总结_Rpc.tex"
```

清理常规辅助文件；TeX 源文件与最终 PDF 会保留。
