# 学习报告

**报告主题：上周课程总结、科研能力反思与研究方向初探**

**学习内容：专业科研核心能力、文献阅读入门**

上周课程围绕“专业科研核心能力”和“文献阅读入门”展开。结合课堂培训资料、7 月 24 日的课堂笔记以及对课题组相关领域综述论文的初步阅读，我对研究生阶段需要建立的能力结构、人工智能实验的基本流程和文献阅读方法有了更系统的认识，并初步梳理了几个值得继续了解的研究方向。在本报告中，我首先总结课程内容，其次记录个人反思、思考与收获，最后说明自己对相关研究现状的初步理解和近期学习计划。

## 一、上周课程内容总结

### 1. 科研是一套相互衔接的完整流程

通过课程资料的学习，我把科研工作理解为一组连续的转换：从研究问题出发，形成数据与假设，再落实为程序与算法，通过实验获得证据，经过分析形成结论，最终完成论文写作与学术交流[1]。因此，我认识到科研不只是提出模型或编写代码，而是由问题发现、文献调研、方案设计、数据处理、实验实现、结果分析和写作表达等环节共同组成的完整流程。我也将科研所需的能力归纳为八个方面：编程、实验复现、数据处理、算法理解、工具使用、结果分析、文献阅读和写作表达[1]。

我认识到，这八项能力并不是相互独立的。例如，算法理解决定我能否把论文中的数学描述转换为代码；数据处理决定我的实验结果是否可信；工具使用会影响我的实验效率和实验的可复现性；结果分析决定我能否从数值中形成有证据支持的结论；写作表达则决定我能否把问题、方法、证据和结论准确传达给他人。现阶段，我认为自己不必急于追求复杂模型，更重要的是先建立一套规范、可重复、可核查的科研工作流程。

### 2. 编程能力与人工智能实验流程

目前我的研究方向尚未完全确定，因此我需要优先加强 Python 基础，并逐步熟悉 NumPy、SciPy、scikit-learn 和 PyTorch 等工具。通过课程学习，我把人工智能实验梳理为以下环节：

1. 数据收集、清洗、预处理与读取；
2. 按照训练集、验证集和测试集进行数据划分；
3. 定义模型结构；
4. 选择损失函数和优化方法；
5. 完成训练、验证和测试；
6. 保存日志、指标、模型参数和实验配置；
7. 分析结果并形成可以复核的结论。

我了解到，张量是深度学习计算的基本数据组织形式，GPU 和 CUDA 可以为大规模张量运算提供加速。CPU 通常承担文件读取、数据预处理和任务调度，GPU 更适合执行大规模并行计算。在学习这些工具时，我不能只记住 API，还需要理解数据形状、数值精度、损失函数、反向传播和评价指标之间的关系。

### 3. 实验复现与数据质量

学习课程资料后，我将复现理解为五个逐步深入的层次：代码复现、流程复现、数值复现、结论复现和机制复现[1]。代码复现关注程序能否运行；流程复现要求我独立完成数据准备、训练与评测；数值复现检查关键指标是否接近论文；结论复现判断相对改进和消融趋势能否重现；机制复现则进一步验证作者对方法有效原因的解释。由此我认识到，复现的目标不是简单地“把代码跑通”，而是理解并检验一项研究的完整证据链。

今后开始复现前，我会系统核对数据集版本、下载方式、预处理、数据划分、模型初始化、损失函数、优化器、学习率、批大小、训练轮数、随机种子、软件与硬件环境、评价指标以及最佳模型选择规则。若我的实验结果与论文不同，我还需要从数据、模型、训练和评测四类因素中定位原因，而不能简单把差异归结为“随机性”。

我也认识到，数据处理同样决定实验是否可信。完整的数据流程包括原始数据检查、格式统一、去重、缺失值和异常值处理、标签检查、数据划分、只使用训练集统计量进行归一化、数据增强与加载。在划分数据时，尤其需要警惕数据泄漏，例如不能在全部数据上计算归一化参数，也不能让同一对象、相邻时间段和重复样本同时进入训练集与测试集。此外，还要关注标签噪声、类别不平衡和分布偏移，因为这些问题会直接影响模型的泛化能力。

### 4. 结果分析与表达

在课堂上，我学习并记录了监督学习中的两类常见任务：分类和回归。分类任务预测离散类别，常用准确率、精确率、召回率和 F1 值等指标；回归任务预测连续数值，通常使用 MAE、MSE、RMSE 或 \(R^2\) 等指标。选择评价指标时需要先明确任务目标，并结合类别是否均衡、不同错误的代价是否相同等条件进行判断，不能只依赖单一的准确率。

为了使自己的实验结论更加可靠，我总结出四个需要重点处理的问题。第一，在进行 Baseline 比较时，我应尽量保证数据、划分、评价指标、测试方式、训练预算和调参条件一致。第二，在进行消融实验时，我应一次只改变一个关键因素，用来验证模块、损失函数、预训练或融合方式是否真正有效。第三，我会使用多个随机种子进行稳定性分析，并在条件允许时报告均值、标准差、置信区间或效应量。第四，我会借助混淆矩阵开展错误分析，并按照类别、难度、数据来源、噪声程度或模型置信度检查失败样本[1]。

我还学习了“主张—证据—推理—局限”（Claim—Evidence—Reasoning—Limitation）的分析框架[1]。在我看来，实验数值和观察属于事实，原因说明属于解释，而结论必须由证据支持，同时还要说明适用范围和局限。我会使用 JSON、CSV 等格式保存实验结果，再通过表格和图形进行展示；除最终数值外，我还会保存训练曲线、超参数、运行环境和异常记录。后续我需要进一步学习 Matplotlib 等可视化工具，并练习使用 Markdown、LaTeX 和 Git 对实验过程进行规范记录。

### 5. 文献类型、检索与阅读方法

通过课程学习，我首先区分了期刊论文、会议论文、预印本、综述论文、学位论文、技术报告和专利等文献类型。我了解到，计算机领域重视会议论文的时效性，而综述论文能够帮助我快速了解一个领域的发展过程、问题分类、代表方法、经典论文、常用数据集、评价指标和开放问题，因此适合作为我进入新方向的第一站。我准备采用课程介绍的领域认知路线：先用 1—2 篇综述建立领域地图，再阅读 5—10 篇经典论文理解方法演进，随后关注近 1—2 年顶会论文了解当前进展，最后通过最新预印本跟踪趋势，同时审慎判断其质量[2]。

检索文献时，把研究问题拆解为技术层、任务层和应用层关键词，再补充同义词和中英文表达，通过 AND、OR 等布尔运算符组合检索式。找到关键综述或代表论文后，可以进一步使用参考文献回溯和被引文献追踪来扩展阅读范围，同时我也会定期浏览本领域的重要会议、期刊和预印本平台。

为了避免把“搜到文献”等同于“找到值得精读的文献”，我学习了三级筛选漏斗：先依据标题、摘要和发表信息进行粗筛，再结合发表渠道、作者、引用、代码、时效性和 Baseline 进行细筛，最后通过三遍阅读法确定必须精读的论文[2]。第一遍，我会用 5—10 分钟扫描标题、摘要、引言、小节标题、结论和参考文献，并从类别、背景、正确性、贡献和清晰度五个方面形成初步判断；第二遍，我会理解全文、图表和核心方法，力求能够解释论文“做了什么、如何做”；第三遍，我会尝试在头脑中重建论文，检查其中的假设、实验和局限，必要时再通过代码复现进行验证[3]。

阅读过程中，我计划从每篇文献中提取研究问题、已有方法及不足、核心假设、创新点、模型与训练方式、数据集、Baseline、评价指标、主要结果、消融实验、失败案例、局限和复现信息，并建立横向比较表。在判断论文价值时，我不能只看期刊分区、会议等级或引用量，还需要考察问题是否真实而清晰、对比是否公平、是否存在数据泄漏、消融是否充分以及结论是否超出证据。我会把人工智能工具用于辅助翻译、提取关键词和整理候选论文，但不会让它代替我对论文质量和研究价值的判断。

## 二、反思、思考与收获

### 1. 对自身科研能力结构的反思

鉴于我本人五年的工作经验来说，对于git使用、python基本语法等都具有一定的了解，同时对项目组织和编码的规范也有不少的认识，因此关于科研的八项核心能力，我认为目前我最需要锻炼的便是数据处理能力。因为传统互联网的代码编写其实也就是数据库的基本操作（CURD）以及部分不是很复杂的算法设计而已，在这个过程中，并未接触过很多的数据处理相关的业务，对于数据处理的能力有所欠缺，在后续的学习中，在增强其他已有能力的同时，我会向数据处理能力的锻炼进行一定的倾斜，以平衡自己的能力分布，促进科研进程。

由于有过具体的业务实现经验，所以我以往的编码更倾向于业务驱动，比如说有了新的bug需要修复；有了新的需求需要实现等。只有具体的问题出来之后我才会行动起来。且在实际业务中我最多就是查查已有的api文档，形成自己编码的文档。但是科研跟业务有着本质的区别，我认为科研更多的要求“主观能动性”，需要自己去发现问题（比如确定研究方向），才能推动科研的整个进程。

在后续的学习中，我会严格按照科研的整个流程，将每一次的实验做到我的极限。

## 三、课题组相关领域的综述阅读与研究现状初探

本次我先根据综述论文的摘要、分类框架、数据集总结和未来展望建立初步的领域地图。下面的内容只是我的阅读起点，并不代表最终选题结论；在确定研究方向前，我还需要精读代表论文、复现实验并与导师讨论。

### 1. 多模态情感分析

通过初步阅读，我了解到多模态情感分析会综合文本、语音、图像或视频中的线索，判断情感极性、情绪类别或更细粒度的情感对象。早期工作主要依赖人工特征和简单融合，随后逐渐转向深度表示学习、注意力机制、跨模态交互和 Transformer。我阅读的综述通常把研究过程概括为单模态表示、时间或语义对齐、跨模态融合以及任务预测[4-7]。

根据目前的阅读，我认为该方向仍有若干值得研究的问题：

- 不同模态在时间、语义和粒度上的对齐；
- 某一模态缺失、质量较差或与其他模态冲突时的稳健学习；
- 反讽、隐含情绪和图文不一致等复杂表达；
- 小样本、标签噪声、数据集偏差和跨数据集泛化；
- 模型输出的可解释性、公平性和隐私问题；
- 大语言模型与传统多模态情感模型的结合。

我认为，这一方向与课题组提到的“多模态情感分析”直接对应，也能让我同时训练文本处理、计算机视觉、深度学习、数据处理和结果分析能力。如果选择它作为入门方向，我准备先选择公开数据集，复现一个基线模型，再比较早期融合、后期融合和跨模态注意力方法，并加入缺失模态或噪声条件下的消融实验。

### 2. 多模态大模型

通过阅读相关综述，我了解到多模态大模型通常由模态编码器、跨模态连接模块和大语言模型组成，并通过多模态预训练、指令微调和偏好对齐，使模型能够理解图像、文本、音频或视频并生成回答。近年的综述重点讨论模型架构、训练数据、对齐方法、评测基准和应用场景[8-9]。

我注意到，该方向发展迅速，但仍面临高质量多模态数据不足、训练成本较高、跨模态幻觉、细粒度感知不足、评测不统一和领域迁移困难等问题。结合我的硕士阶段学习条件，我认为直接从头训练大模型的成本过高，更现实的切入方式可能是：

- 对开源多模态模型进行参数高效微调；
- 构建某个专业领域的小规模高质量数据集；
- 研究多模态模型在情感识别或图像理解任务中的评测方法；
- 分析幻觉、鲁棒性、偏差或提示方式对结果的影响；
- 将多模态大模型与检索系统结合，增强专业知识和结果可追溯性。

### 3. 信息检索与检索增强生成

通过阅读相关综述，我了解到检索增强生成（Retrieval-Augmented Generation，RAG）把外部知识检索与生成模型结合，使模型在回答前检索相关证据。最新综述将研究重点归纳为检索器、检索结果融合、生成器、训练方式和评价方法，并进一步关注知识更新、领域适配、效率、安全和图结构检索等问题[10,12]。

我在课堂笔记中记录过“数据检索”和“大模型”，因此我认为这一方向与课程内容联系紧密，工程入口也相对清晰。我可以从课程资料或课题组文献出发构建一个小型知识库，比较不同文本切分方法、向量模型、稀疏检索、重排序方法和提示模板，再使用 Recall@k、MRR、答案正确性、忠实性和引用可追溯性等指标进行评价。我也需要特别注意，检索到相关文档并不等于生成结果一定可靠，检索噪声、错误引用和评价标准仍是需要研究的问题。

### 4. 图像识别与视觉 Transformer

通过初步阅读，我了解到图像识别是计算机视觉的基础方向，研究任务包括图像分类、目标检测和图像分割等。视觉 Transformer 通过自注意力建模全局关系，已经扩展到图像识别、检测、分割、视频理解和视觉问答等任务[11]。我认为该方向的研究体系和公开基线比较成熟，适合用来训练自己的规范实验能力。

如果我选择这一方向，我会先在规模适中的公开数据集上比较卷积神经网络与视觉 Transformer，保持相同的数据划分和训练预算，分析数据规模、模型复杂度、计算开销、鲁棒性与泛化表现。后续我再考虑将其与多模态学习结合，而不会一开始就追求过大的模型。

## 五、综述阅读顺序与近期计划

我将先按照课程提出的“综述—经典论文—近期顶会论文—最新预印本”路线建立领域认知，再按照“基础框架—具体任务—前沿模型—工程方向”的顺序阅读：

1. 我先阅读 Baltrušaitis 等的多模态机器学习综述[4]，理解表示、对齐、融合、翻译和协同学习的基本分类。
2. 我再从多模态情感分析综述[6-7]中选择一篇精读，记录常用数据集、代表模型、评价指标和开放问题。
3. 随后，我阅读多模态大模型综述[8-9]，重点比较模型结构、训练阶段、数据需求和评测方式。
4. 如果我对检索方向保持兴趣，我会阅读最新的 RAG 综述[10]，并将其中的检索与融合分类转化为一个可运行的小实验。
