# Assignments

课程作业与学习报告归档。

每份作业使用独立目录，推荐命名为 `YYYY-MM-DD-short-topic`，目录内包含：

- `README.md`：任务背景、完成情况、构建方式和总结。
- 源文件：例如 `.tex`、代码或数据处理脚本。
- 最终成品：例如 `.pdf`。
- 必要资源：图片、参考文献等放在同一目录的 `assets/` 中。  
> 根据实际情况可能有所改动
