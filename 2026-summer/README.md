# 2026 暑期学习总览

本目录用于集中记录 2026 年暑期的课程学习、技术积累和实践过程。重点不是单纯收集文件，而是形成“学习—实践—总结—改进”的闭环。

## 暑期目标

- 夯实 Linux、Markdown、LaTeX 和版本管理等科研基础工具。
- 持续复习编程语言，并用小项目验证所学知识。
- 对课程作业和技术笔记进行可复现、可检索的归档。
- 保持每周复盘，记录问题、决策和下一步行动。

## 分类说明

- [assignments](assignments/)：课程作业、报告、源文件和最终成品。
- [notes](notes/)：知识点、读书笔记、工具用法和问题排查。
- [projects](projects/)：课程实验、编程练习和可运行的小项目。
- [reflections](reflections/)：周复盘、阶段总结和个人思考。
- [resources](resources/)：书籍、论文、课程和工具资料索引。

## 推荐节奏

1. 学习前：在对应笔记或项目中写下目标和待解决的问题。
2. 学习中：记录关键概念、命令、实验过程以及失败原因。
3. 学习后：补充总结、结果和仍未解决的问题。
4. 每周末：从 [周复盘模板](../templates/weekly-review-template.md) 新建一份复盘。
5. 完成内容后：更新本页索引与仓库首页。
