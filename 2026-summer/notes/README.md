## 命名建议

- 单篇笔记：`YYYY-MM-DD-topic.md`（可简略为MM.DD，毕竟后续会分大的目录）
- 持续更新的专题：`topic/README.md`
- 配图与附件：放入该笔记旁的 `assets/` 目录

新建笔记时可复制 [笔记模板](../../templates/note-template.md)。笔记完成后，在 [暑期学习总览](../README.md) 中补充索引。
