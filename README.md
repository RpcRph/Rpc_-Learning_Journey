## 仓库结构

```text
.
├── 2026-summer/
│   ├── assignments/    # 课程作业、报告及其源文件
│   ├── notes/          # 按主题整理的学习笔记
│   ├── projects/       # 可运行的小项目与实验
│   ├── reflections/    # 周复盘、阶段总结与想法
│   └── resources/      # 资料索引与阅读清单
└── templates/          # 新增内容时可复用的模板
```

## 维护约定

1. 文件和目录使用 `YYYY-MM-DD-topic` 命名，路径中的主题尽量使用简短英文。
2. 每份作业单独建目录，同时保留源码、最终成品和说明文件。
3. 笔记重在记录自己的理解；引用资料时附上来源链接。
4. 项目目录至少包含目标、运行方法、结果和后续改进。
5. 每周在 `reflections/` 中记录本周完成内容、问题和下周计划。
6. 提交信息使用 `docs:`、`notes:`、`homework:`、`project:` 等前缀，便于查看历史。
